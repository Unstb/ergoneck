# ErgoNeck

Одностраничный сайт хакатон-проекта ErgoNeck.

## Как опубликовать через GitHub Pages

1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите в корень репозитория все файлы из этого архива.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Укажите ветку **main**, папку **/(root)** и нажмите **Save**.
6. Через несколько минут ссылка появится в этом же разделе.

Главная страница — `index.html`. Сборка и дополнительные зависимости не требуются.
